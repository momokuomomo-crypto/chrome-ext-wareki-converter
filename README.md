# 和暦変換（改元日対応）— Chrome 拡張機能

西暦と和暦を**日付単位で**相互に変換する Chrome 拡張機能です。

```
入力：1989/1/8

  平成元年1月8日
  1989年1月8日
  ※ 1989年は1月7日までが昭和64年、1月8日からが平成元年
```

## 既存の和暦変換拡張との違い

**改元のあった年は、境界日を注記で示します。**

同じ 1989 年でも、1月7日までは昭和64年、1月8日からは平成元年です。この境界を能動的に教えるのが本拡張の要点です。`昭和64年1月8日` のような**存在しない和暦は作りません**。それを入力した場合は、期間外であることを示したうえで「この日付は 平成元年1月8日 です」と正解を併記します。

あわせて、全角・元年表記・元号略号・区切りなし8桁・曜日付き・先頭ラベル付きの入力を受理します。

## できること

- **双方向**：西暦→和暦、和暦→西暦。主に表示する形式を切り替えられます
- **入力は2通り**：ポップアップに手入力／ページ上の日付を選択して右クリック
- **年だけでも変換できます**：`1901` は明治34年。改元のあった年は両方を境界つきで並べます
- **表記ゆれを吸収**：`1989/1/8` `19890108` `1989年1月8日` `平成元年1月8日` `H1.1.8` `H1年1月8日` `H元/1/8` `西暦1989年1月8日` 全角数字、`生年月日：1989年1月8日`、`1989年1月8日（日）`

## 使ってみる

ビルド不要です。`dist` フォルダをそのまま Chrome に読み込めます。

```
git clone https://github.com/momokuomomo-crypto/chrome-ext-wareki-converter.git
```

`chrome://extensions` → デベロッパーモードをオン → 「パッケージ化されていない拡張機能を読み込む」→ `dist` フォルダを選択。

## 権限

`contextMenus`・`storage`・`notifications` の3つだけです。ページの内容を読み取る権限（`host_permissions`・`activeTab`・`scripting`）は要求せず、**外部通信も一切行いません**。

## 制限事項

- **1873年1月1日（明治6年1月1日）以降**のみ対応します。明治5年以前は旧暦のため、元号年から西暦への機械換算が成立しません
- 同梱の元号データには確認期限があります。それを超える日付も変換しますが、**以降に改元があった場合は正しい和暦が異なる旨の注記**が付きます
- 右クリックの結果は Chrome の通知に表示します。OS 側で通知が抑制されている場合（Windows の集中モード等）は検知できません。その場合はポップアップに結果が残ります

## 開発

```
npm install
npm test        # 単体・統合テスト（99件）
npm run verify  # ビルド → dist の検査
```
